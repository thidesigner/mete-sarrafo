# Sugestões dos amigos

Cada arquivo aqui guarda sugestões recebidas, com a data no nome (ex.: `2026-10-29.md`).

De onde elas vêm:

- **Site (modo online e sem conta):** no celular de quem criou a sala, na tela de Regras/Ideias, o botão **Copiar sugestões** junta tudo num texto. Cole para o Claude, que salva aqui.
- **Jogo dentro do Claude (Modo Festa):** ficam no banco `sugestoes` do artefato; o Claude lê quando pedirem.
- **Formulário Google (em preparação):** quando estiver ligado, as sugestões do site vão direto para uma planilha do Drive.

Para cada lote, o Claude resume o que a turma curtiu, o que mais pediram para mudar e propõe o próximo teste.
